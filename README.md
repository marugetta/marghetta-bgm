# マルゲッタ BGM プレーヤー

SUNO（Premierプラン）で作った曲を、店舗のスマホから流すためのWebプレーヤーです。

## 曲の追加方法（GitHubのサイトから）
1. このリポジトリの `music/lunch` などのフォルダを開く
2. 右上の **Add file → Upload files** で MP3 をドラッグ＆ドロップ（1回100ファイル・1曲25MBまで）
3. **Commit changes** を押す
4. 2〜3分で、プレーヤーに曲が反映されます（曲リストは自動作成）

- 曲名は **ファイル名** がそのまま表示されます（例：`博多ブリーズ.mp3` → 博多ブリーズ）
- 曲を消すときは、そのファイルを開いて右上の「…」→ Delete file

## プレイリスト
`music/` の中のフォルダが、それぞれプレイリストになります。

| フォルダ | 表示名 |
|---|---|
| music/lunch | ランチ |
| music/dinner | ディナー |
| music/common | 共通（ランチとディナーの両方で流れる） |
| （全部） | すべての曲 |

ランチでもディナーでも流したい曲は、`music/common` に1回だけ入れてください。

フォルダを増やしたら、`config.json` の `labels` に表示名を追加します（書かなくてもフォルダ名で表示されます）。

## タグ（#ハロウィン など）
`tags.json` に「タグ名 → 曲名の一覧」を書くと、プレーヤーにタグのボタンが出ます。

```json
{
  "ハロウィン": [
    "マルゲッタのハロウィン",
    "TRI-TRI-TRICK OR TREAT"
  ]
}
```

- 曲名は、プレーヤーに表示される名前と同じに書きます（`.mp3` は不要）
- 1曲に複数のタグを付けられます（いくつかのタグの一覧に同じ曲名を書く）
- GitHub で `tags.json` を開き、鉛筆マーク（Edit）で編集 → **Commit changes**。2〜3分で反映されます

### プレーヤーでの使い方
- タグのボタンを押すか、検索欄に曲名や `#ハロウィン` を入れると、該当する曲だけが下に表示されます
- **順番に再生**：表示されている曲を上から順に再生
- **シャッフル**：表示されている曲をシャッフルして再生
- 曲名をタップすると、表示されている曲の中でその曲から再生します
- 絞り込み再生中は再生画面に「#ハロウィン だけ再生中 ×」と出ます。× で全曲の再生に戻ります

## BPM（テンポ）
`bpm.json` に各曲のBPMが入っていて、プレーヤーの再生画面と曲一覧に表示されます。
テンポの違う曲が混ざっていると「♩ ゆったり／ふつう／アップテンポ」のボタンが出て、テンポで絞り込めます（タグや検索と組み合わせ可）。全曲が同じ区分のときはボタンは出ません。

- BPMは曲の音から自動で測った値で、±2くらいの誤差があります。バラードなどは本来の半分や2倍の値になることがあります
- 値を直すときは、`bpm.json` を開いて数字を書き換えて **Commit changes**
- 新しい曲を追加したら、`python3 scripts/measure-bpm.py` を実行すると、まだ測っていない曲だけを測って `bpm.json` に追加します（Python・ffmpeg・librosa が必要）。BPMがない曲も、表示されないだけで普通に再生できます
- テンポの区切り（110・128）は `index.html` の `TEMPOS` で変えられます

## お気に入り（★）
曲の ☆ を押すと ★ になり、お気に入りに入ります。タグの並びの「★ お気に入り」で、お気に入りの曲だけを表示・再生できます。

- お気に入りは **そのスマホ（ブラウザ）だけ** に保存されます。ほかの人のスマホとは共有されません
- **iPhoneはホーム画面のアイコンから使ってください**。Safariで開いたときとは保存場所が別で、ホーム画面版はSafariの履歴・データを消しても残ります（アイコンを削除すると消えます）
- **Android**は「Cookieとサイトデータ」を削除すると消えます（閲覧履歴の削除だけなら残ります）
- 一覧のいちばん下の「バックアップ」でお気に入りを文字にしてコピーできます。メモやLINEに保存しておき、消えたときや機種変更のときは「復元」に貼り付けます
- 曲名（ファイル名）を変えると、その曲のお気に入りは外れます

## テンポ（再生速度）
再生画面の「テンポ」のつまみで、**音程を変えずに** 80%〜120% の範囲で速さを変えられます（5%きざみ）。
- 右の「90%」などのボタンを押すと 100% に戻ります
- 設定はその端末に記憶され、次の曲や次に開いたときもそのままです
- BPMの表示は、変えたあとの速さで表示されます
- ±10%くらいまでは自然に聞こえます。大きく変えると音が少しにじむことがあります

## 時間帯の自動切替
`config.json` の `schedule` で設定します。曲の途中では切り替わらず、今流れている曲が終わってから次のプレイリストに移ります。
プレーヤー右上の「⏰ 自動」でON/OFFを切り替えられます。

## 店舗スマホでの使い方
- URLをホーム画面に追加しておくと、アプリのように開けます
- 「☀ 画面ON」がONだと、再生中は画面が消えません（端末の自動ロックをOFFにするとより確実）
- iPhoneはプレーヤーで音量を変えられないので、本体の音量ボタンで調整してください
